Personal Inventory System / ERP Lab for personal comprehension of Containers, Databases, Networking, Security, etc. :-)

How To Run:
CD in the Main Directory. 
sudo docker compose build
sudo docker compose run

Port 8080 is the Nginx Server
Port 9001 is the API 

To test the Update Products feature, need to go directly to:
127.0.0.1:9001/docs

Very basic for now but it's growing :-)
