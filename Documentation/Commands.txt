Datatypes:
	Numbers:
		INTEGER
		BIGINT
		NUMERIC(10,2) --- Base 10 2 digits after comma
	Text:
		VARCHAR(100) --- String Length
		TEXT --- Unlimited Length
	Dates:
		DATE
		TIMESTAMP
		TIMESTAMPTZ
			Ex: created_at TIMESTAMPTZ DEFAULT NOW()
	State:
		BOOLEAN

Primary Keys:
	Sets the most important column.
	While creating the table, let's say we add the following column:
		id SERIAL
	Set it as Primary:
	id SERIAL PRIMARY KEY
Foreign Keys:
	Ex: supplier_id INTEGER REFERENCES suppliers(id)
		The data in column suppliers_id in the present table MUST REFERENCE an existing id in the table suppliers.
